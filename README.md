# Flookes HQ — family.flookesitup.com

The Flookes family organizer: tasks and chores, the kids' chore bank and savings goals,
the weekly dinner plan and shopping list, the family Google Calendar, weather, and push
notifications. It runs entirely on Cloudflare: one Worker serves the app and its API, and
everything is stored in a D1 database. (It used to run on GitHub Pages + Supabase + three
separate Workers; that setup is in `z_archive/` and git history.)

## How it fits together

| | |
|---|---|
| `public/` | The app: `index.html` (PIN sign-in), `app.html` (everything else), `db.js` (database client), `sw.js` (offline + push), icons, manifest |
| `src/worker.js` | Sign-in, the API, Google Calendar, AI features, push sending and the scheduled jobs |
| `src/query.js` | Runs the app's database queries on D1 and enforces who can do what |
| `src/schema.js` | The tables (they create themselves on first use) |
| `src/push.js` | Web push encryption and the push keys |

## Sign-in and permissions

- Tap your name, enter your 4-digit PIN. The PIN is checked on Cloudflare's server and stored
  scrambled (PBKDF2). The phone stays signed in for 90 days (secure, HttpOnly cookie).
- 8 wrong PINs on one person's tile locks that tile for 15 minutes.
- Change your PIN: tap your name (top right) → **Change my PIN**. Parents can also reset a kid's PIN there.
- Kids can only see their own bank account (read-only), their own savings goals, their own
  tasks and race chores, and only calendar events with their name in the title (3 days).
  Parents can do everything. These rules are enforced by the server, not just hidden in the page.

## Chores

- **Who:** a specific kid, **each kid** (everyone gets their own copy and is paid separately) or
  **first to grab** (one copy; the first kid to tap "I did it" gets it).
- **Repeating chores** are set up once by a parent (Tasks → 🔁 Repeating chores): days of the
  week, optional due-by time, optional date range, pause. The Worker hands out each day's copies
  just after midnight Pacific — phones never create them.
- **Deadlines:** a chore not checked off by its due-by time (or midnight) is **missed** — no pay.
  Checked off in time = paid whenever a parent approves. **Send back** (↩︎) returns it to the kid
  with an optional note; after the deadline it counts as missed.
- **Reminders:** push 1 hour before a due-by time, or 7 PM for chores due at midnight.
- Parents see "chores missed this week" per kid on the Bank tab.

## Live updates

The app checks for changes when it's opened and every 15 seconds while it's on screen, and
refreshes the tasks, shopping list or meals if someone else changed them.

## Scheduled jobs

One cron every 15 minutes (`*/15 * * * *`): hands out repeating chores, marks missed chores and
sends chore reminders. In Pacific time, once a day: 7 AM weather, due-today reminders and the
payout check; Sunday 10 AM meal-plan reminder if the week is empty.

## Secrets (Worker → Settings → Variables and Secrets)

| Name | For |
|---|---|
| `ANTHROPIC_API_KEY` | Recipe import, meal suggestions, shopping list clean-up |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN` | The family Google Calendar |

Push notification keys are generated by the Worker and kept in D1 — nothing to set.

## Deploying

Cloudflare builds and deploys automatically on every push to the production branch
(Workers & Pages → flookes-hq → Settings → Build).

**Running locally:** `npm install`, copy `.dev.vars.example` to `.dev.vars`, `npm run dev`,
open http://localhost:8787.

## Backups

D1 Time Travel keeps restore points for the database (7 days on the free plan).
